## What I have to do
Prior to each Tuesday morning class , write a short summary of the article or articles to be discussed that week: 
one paragraph summarizing the article(s), 
and a second paragraph describing your reaction (for example, aspects that you found surprising, interesting, or suspect). 
The written summary should be less than a page but more than a couple of sentences. 
Also include two or more discussion questions that might be used to stimulate discussion of the paper.

## Organization
My plan is to have a folder for each week (e.g. week1, week2, ..., weekn) and have a summary markdown file that contains the summary and reaction to each article (e.g. summary.md).
